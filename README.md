# Лабораторная работа №4

Классификация характеристик товара по отзыву.

Программа принимает отзыв, разбивает его на слова и делит их на положительные,
отрицательные и нейтральные. Затем выводит общую оценку отзыва:
положительный, отрицательный, смешанный или нейтральный.

## Файлы

- `main.py` — программа

## Запуск

```bash
python main.py
